# Генератор изображений LCD1602

Приложение на Qt Quick для подготовки изображений, имитирующих дисплей
LCD1602: 16 символов в 2 строки, каждый символ рисуется матрицей 5x8.
Интерфейс написан на QML, состояние проекта, загрузка/сохранение и экспорт
PNG реализованы в C++ бэкенде.

## Возможности

- Превью дисплея LCD1602 16x2.
- Ввод двух строк, максимум 16 символов в строке.
- Выбор текущей позиции кликом по ячейке дисплея.
- Мигающий курсор выбранной позиции, похожий на нижнее подчеркивание LCD.
- Темы: зеленая LCD, монохромная, синяя.
- Ручная настройка цветов фона, пикселей и подсветки.
- Включение/выключение пиксельной сетки и рамки устройства.
- Редактор 8 пользовательских символов CGRAM.
- Вставка пользовательского символа в выбранную позицию дисплея.
- Редактор символов шрифта 5x8 с рисованием протягиванием мыши.
- Добавление в шрифт сразу набора символов, например `ABCxyz0123`.
- Сохранение/загрузка проекта в JSON.
- Загрузка/сохранение шрифта в BDF.
- Экспорт изображения в PNG с масштабом x1, x2, x4 или x8.

## Формат шрифта

Внешний шрифт должен предоставляться в формате **BDF** (`.bdf`,
Glyph Bitmap Distribution Format). Это распространенный текстовый формат
bitmap-шрифтов из экосистемы X Window System. Он лучше подходит, чем
самодельный JSON, потому что:

- формат документирован и давно используется;
- файл можно просматривать и редактировать как обычный текст;
- каждый символ хранит код Unicode/ASCII через `ENCODING`;
- пиксельная карта символа задается в блоке `BITMAP`;
- формат естественно описывает монохромные растровые шрифты.

Для LCD1602 ожидается моноширинный шрифт:

- `BBX 5 8 0 0` для каждого символа;
- 8 строк bitmap-данных на символ;
- в каждой строке используются старшие 5 бит байта;
- `DWIDTH 6 0`, где шестая колонка работает как межсимвольный промежуток.

Минимальный пример символа `A`:

```bdf
STARTCHAR uni0041
ENCODING 65
SWIDTH 500 0
DWIDTH 6 0
BBX 5 8 0 0
BITMAP
70
88
88
F8
88
88
88
00
ENDCHAR
```

Строка `70` в бинарном виде соответствует `01110xxx`: первые пять бит
используются как пиксели матрицы 5x8, оставшиеся три бита игнорируются.

Базовый шрифт проекта находится в
[`fonts/lcd1602-5x8.bdf`](fonts/lcd1602-5x8.bdf). Такой же набор символов
инициализируется в бэкенде и используется по умолчанию при запуске.

## Редактирование шрифта в приложении

1. В блоке «Редактор шрифта 5x8» введите один или несколько символов в поле
   «Добавить символы», например `ABC012+-`.
2. Нажмите «Добавить». Новые символы появятся в списке кнопок шрифта.
3. Выберите нужный символ кнопкой из списка.
4. Отредактируйте его матрицу 5x8 кликами по пикселям или зажмите кнопку
   мыши и протяните по сетке. Один жест либо рисует пиксели, либо стирает их,
   в зависимости от первого пикселя под курсором.
5. Повторите это для всех нужных символов.
6. Нажмите «Сохранить весь шрифт». В файл BDF попадет весь текущий набор
   символов, а не только последний выбранный символ.

## Формат проекта

Проект сохраняется в JSON. В нем хранится все редактируемое состояние:
текст, цвета, настройки экспорта, кастомные символы и текущий шрифт.

```json
{
  "format": "lcd1602-image-generator",
  "version": 1,
  "text": ["LCD1602", "GENERATOR"],
  "colors": {
    "bg": "#19381f",
    "pixel": "#b6ff65",
    "backlight": "#6ba842"
  },
  "showGrid": true,
  "deviceFrame": true,
  "exportScale": 4,
  "customChars": [],
  "font": {}
}
```

Внешние файлы шрифтов рекомендуется хранить отдельно в BDF.
