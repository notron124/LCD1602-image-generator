# Техническое задание

**Проект:** Веб-генератор изображений LCD1602
**Цель:** Создание веб-инструмента для генерации изображений, имитирующих экран LCD1602, с возможностью кастомизации текста, символов, шрифтов и цветовых схем.

---

## 1. Общие требования

### 1.1 Назначение

Веб-страница должна позволять пользователю:

* создавать изображения, имитирующие LCD1602 (16×2 символов),
* редактировать содержимое экрана,
* использовать кастомные символы и шрифты,
* экспортировать результат в виде изображения.

---

## 2. Функциональные требования

### 2.1 Эмуляция дисплея

* Размер: 16 символов × 2 строки.
* Каждый символ — матрица 5×8 пикселей (классический LCD1602).
* Отображение:

  * пиксельная сетка (включаемая/отключаемая),
  * реалистичный стиль LCD (фон + подсветка + пиксели).

---

### 2.2 Ввод текста

* Поле ввода текста:

  * поддержка двух строк (перенос или отдельные поля),
  * ограничение длины (16 символов на строку),
  * возможность ручного размещения символов (позиционирование курсора).
* Поддержка:

  * ASCII
  * пользовательских символов (CGROM/CGRAM аналог)

---

### 2.3 Цветовые режимы

* Предустановленные режимы:

  * черно-белый
  * оригинальный (зеленый LCD)
  * (опционально) синий LCD
* Возможность:

  * кастомной настройки:

    * цвет фона,
    * цвет пикселей,
    * цвет подсветки.
* Переключение темы в реальном времени.

---

### 2.4 Кастомные символы

* Редактор символов:

  * сетка 5×8 пикселей,
  * включение/выключение пикселей кликом.
* Ограничения:

  * до 8 пользовательских символов (как в реальном LCD1602).
* Возможности:

  * сохранение символов (локально, JSON),
  * загрузка символов,
  * вставка символа в текст.
* Примеры:

  * галочка
  * стрелки
  * иконки

---

### 2.5 Работа со шрифтами

* Поддержка:

  * стандартного LCD шрифта (по умолчанию),
  * пользовательских шрифтов.
* Функции:

  * загрузка шрифта (JSON/bitmap формат),
  * редактор шрифта:

    * редактирование каждого символа (5×8),
  * сохранение шрифта,
  * переключение активного шрифта.
* Формат хранения:

```json
{
  "A": [[0,1,1,0,0], ...],
  ...
}
```

---

### 2.6 Генерация изображения

* Форматы экспорта:

  * PNG (обязательно),
  * SVG (опционально).
* Возможности:

  * масштабирование (x1, x2, x4, x8),
  * сохранение с/без сетки,
  * сохранение с рамкой устройства (опционально).
* Кнопка:

  * «Сохранить изображение».

---

### 2.7 Сохранение и загрузка проектов

* Возможность:

  * сохранить проект (JSON):

    * текст,
    * шрифт,
    * кастомные символы,
    * цветовая схема.
* Загрузка проекта:

  * из файла,
  * (опционально) из localStorage.

---

## 3. UI/UX требования

### 3.1 Интерфейс

Блоки:

1. Превью дисплея
2. Ввод текста
3. Панель настроек:

   * цвета
   * масштаб
4. Редактор символов
5. Редактор шрифтов
6. Кнопки:

   * сохранить изображение
   * сохранить проект
   * загрузить проект

---

### 3.2 Удобство использования

* Живое обновление превью
* Drag & drop для загрузки файлов
* Горячие клавиши (опционально):

  * стрелки — перемещение курсора
  * Enter — переход на следующую строку

---

## 4. Технические требования

### 4.1 Технологии

* Frontend:

  * HTML5
  * CSS3
  * JavaScript (желательно React или Vue.js)
* Canvas API для рендеринга
* Без обязательного backend (SPA)

---

### 4.2 Архитектура

* Модули:

  * Render Engine (отрисовка LCD)
  * Font Manager
  * Symbol Manager
  * Export Module
  * Storage Module

---

### 4.3 Производительность

* Мгновенное обновление (<50 мс)
* Оптимизация Canvas перерисовки
